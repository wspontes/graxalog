Sistema de Gestão de Entregas

Operação de Logística Local — Última Milha

Proposta Técnica

1 Visão Geral

Sistema web completo para gerenciar o fluxo operacional de uma empresa de logística local de pequeno porte (até 10 entregadores). A empresa recebe carga de um centro de distribuição com nota fiscal/romaneio e precisa controlar: recebimento → conferência por QR Code → armazenamento → roteirização → distribuição → entrega → acompanhamento em tempo real.

O sistema não inclui cadastro de clientes, emissão fiscal, financeiro, ERP ou controle de veículos — foco exclusivo na última milha.

2 Perfis de Usuário

Administrador (Dono): Acesso completo via painel web (desktop). Responsável por conferir pacotes, importar romaneios, gerenciar entregadores, roteirizar, distribuir, acompanhar entregas e exportar relatórios.

Entregador: Acesso via site responsivo mobile-first (PWA). Visualiza rotas, atualiza status, adiciona observações e consulta detalhes dos pacotes.

Autenticação simples (usuário/senha) sem OAuth.

3 Fluxo Operacional

Importação da Carga

XLSX ou PDF (extração automática) ou cadastro manual com foto do romaneio

Conferência (Bipagem)

Leitura contínua de QR Code com validação, alertas de duplicados e códigos sem correspondência

Armazenamento

Status "Em estoque" com filtros por bairro, data, código, destinatário

Roteirização

Geocodificação via API de mapas, agrupamento por proximidade, ordem otimizada, drag-and-drop

Distribuição e Entrega

Atribuição manual de rotas, PWA com fila offline, registro de entregas com foto para terceiros

4 Diferenciais do Sistema

Offline
Fila local de sincronização automática para o entregador
Realtime
WebSocket (Socket.io) para atualização instantânea no painel
QR Code
Leitura contínua com tratamento de duplicados e códigos avulsos
Falha de Geo
Endereços não localizados ficam em lista separada com correção manual ou pino no mapa
Histórico
Cada pacote possui timeline completa de eventos desde a importação
Encerramento
Rota pode ser encerrada com pendências; pacotes retornam ao estoque

5 Pilha Tecnológica

React / Next.js Tailwind CSS Node.js Express / Fastify PostgreSQL Socket.io Google Maps / Mapbox / OSRM PWA XLSX / PDF

Dashboard & Relatórios

Painel com indicadores em tempo real (esperados, conferidos, estoque, em rota, entregues, ausentes, terceiros) e gráficos de desempenho por entregador, tempo médio por rota e taxa de sucesso. Exportação em XLSX e PDF.
